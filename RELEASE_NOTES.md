# Sarex Loader — первый выпуск для приёмки

Версия пакета: **v0.1.0-rc.8**. Это первый опубликованный выпуск; `rc.8` — технический номер сборки кандидата, а не перечень ранее опубликованных релизов.

## Назначение

Программа сопоставляет инспекционные PDF с Excel-реестрами, определяет папки Sarex, загружает документы после подтверждения и восстанавливает пустые ссылки в Excel. СК и ВК запускаются отдельно.

## Возможности

- `-preview sk/vk` и `-load sk/vk --dry-run`: реальные метаданные Sarex, проверка назначений и отчёты без отправки, перемещения PDF или изменения Excel.
- `-test-pdf`: подготовка одного синтетического PDF для фиксированной папки 99-Тест. Отправка — отдельной командой с хешем плана и подтверждением; повтор использует сохранённый журнал.
- `-load sk/vk`: план и подтверждение пользователя; проверка номеров, дат, маршрутов и дублей; последовательная отправка подходящих PDF, проверка результата и сохранение URL в переданный Excel.
- PDF с доказанно отсутствующим в Excel номером при рабочем запуске перемещается в локальную подпапку «не найдено». `--no-move` запрещает это перемещение, но не загрузку остальных файлов.
- `-fill sk/vk`: заполнение только пустых URL в переданном Excel по однозначным документам Sarex. PDF на компьютере не требуются. Перед сохранением создаётся резервная копия.
- `-folders on/off/status`: управление созданием месячных папок, **по умолчанию off**. При on рабочий load отдельно запрашивает подтверждение списка. Создаются только месяцы внутри подтверждённых родителей; офисы и подрядчики автоматически не создаются. После создания нужен повторный запуск для PDF.
- Русская справка, автоматическая папка отчётов, Markdown/CSV, подробный журнал, checkpoint обхода и постоянные SQLite-журналы. Неопределённые операции не повторяются автоматически.

## Поставка и запуск

[Релиз и архивы Windows/macOS](https://github.com/alesulkins/sarex-loader/releases/tag/v0.1.0-rc.8).

Нужны Python 3.11+ (для новой установки обычный Python 3.13/3.14), интернет и учётная запись Sarex. Архивы содержат код и запускатель, а не автономный EXE. При первом запуске устанавливаются зависимости. Авторизация в клиентских ZIP пустая, настраивается через `-setup`.

Пошаговая установка и команды: [README.md](README.md). Сценарии и критерии приёмки: [ACCEPTANCE.md](ACCEPTANCE.md).

## Ограничения и условия приёмки

**Объём партии:** не запускайте сразу папку с тысячами PDF, например 10 000–20 000. Такой объём не прошёл приёмку текущей поставки. Сначала проверьте сценарии по одному PDF, затем используйте отдельные рабочие папки по **10–20 PDF**, каждый раз выполняя preview/dry-run и проверяя итоговый отчёт. Это рекомендация для осторожного начала, а не гарантированный лимит или обещание успешной загрузки каждого файла. Точное число, которое «обязательно пройдёт», не установлено: результат зависит от данных, маршрутов, прав, сети и Sarex. Увеличивать партии можно только после успешной проверки заказчиком. Уменьшение числа PDF не сокращает рекурсивный обход выбранного корня Sarex; обработка может занять время. Не запускайте одну партию одновременно в нескольких процессах или на разных компьютерах.

Можно передавать заказчику для контролируемой приёмки, начиная с preview и dry-run, затем 99-Тест и согласованных сценариев по одному PDF. До рабочей отправки заказчик обязан прочитать отчёты и план: проверить реестр, офис, подрядчика, месяц, полный путь и ID каждой цели. Для проверки fill используется копия Excel.

Наличие команды не является разрешением на массовую загрузку. Папки по умолчанию не создаются; для их приёмки нужны права аккаунта и отдельное согласование. При конфликтных данных, неоднозначности, ошибках чтения или UNKNOWN нельзя обходить защиту и сбрасывать SQLite.

После передачи заказчик отвечает за проверку данных и назначений, выбор аккаунта и каталогов, подтверждение операций, резервные копии и дальнейшую эксплуатацию. Preview описывает предполагаемый результат на момент чтения; изменения данных, прав или Sarex могут повлиять на дальнейший запуск. Передача для приёмки не означает гарантии работы с любыми данными или завершения приёмки всех функций. Полные условия использования изложены в разделе 11 README.
